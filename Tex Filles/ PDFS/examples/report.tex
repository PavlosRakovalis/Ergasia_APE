\begin{abstract}
Στην παρούσα εργασία εφαρμόζεται η μέθοδος f-Chart για τη διαστασιολόγηση ηλιοθερμικού συστήματος παραγωγής Ζεστού Νερού Χρήσης (Ζ.Ν.Χ.) σε ξενοδοχείο \num{300} κλινών εντός κλιματικής ζώνης \textDelta. Τεκμηριώνονται οι παραδοχές και τα δεδομένα με αναφορές στις τεχνικές οδηγίες ΤΟΤΕΕ 20701-1/2017 και ΤΟΤΕΕ 20701-3/2010, και παρουσιάζεται ο κώδικας (MATLAB) που χρησιμοποιήθηκε ανά υποερώτημα.
\end{abstract}

\subsection{Ημερήσιο φορτίο Ζ.Ν.Χ.}
Για ξενοδοχείο ετήσιας λειτουργίας \num{300} κλινών, η \emph{ημερήσια κατανάλωση Ζ.Ν.Χ.} ανά κλίνη λαμβάνεται από τον \emph{Πίνακα 2.5} της ΤΟΤΕΕ~20701-1/2017. % Εικόνα από ΤΟΤΕΕ 20701-1/2017, Πίνακας 2.5

\section{Μεθοδολογία f-Chart}
Για μηνιαία ανάλυση $i=1,\dots,12$, το φορτίο $L_i$ (σε \si{\joule}) υπολογίζεται από:
\begin{equation}
Q_{\mathrm{dem,HW},i} = V_d \, N_{\mathrm{day},i}\, \rho \, C_p \, (T_{hw}-T_{cw,i}),
\end{equation}
και κατόπιν προσαυξάνεται για απώλειες δεξαμενής/διανομής:
\begin{equation}
L_i = \frac{Q_{\mathrm{dem,HW},i}}{\eta_{\mathrm{ls}} \cdot \eta_{\mathrm{em}}}.
\end{equation}
% Εικόνα/απόσπασμα: Οδηγός εργασίας/ΤΟΤΕΕ 20701-1 για τον ορισμό φορτίου και προσαύξηση λόγω απωλειών

Οι αδιάστατες παράμετροι της f-chart δίνονται από:
\begin{align}
X_i &= \frac{A_c}{L_i} \, \frac{F R U_L}{F'R/F R}\, (T_0-\bar{T}_{a,i}) \, \Delta t \, k_1 k_2, \\
Y_i &= \frac{A_c}{L_i} \, \frac{F R (\tau \alpha)_n}{F'R/F R}\, \frac{\tau \alpha}{(\tau \alpha)_n} \, \bar{H}_{\beta,i}\, k_3,
\end{align}
και ο μηνιαίος συντελεστής κάλυψης:
\begin{equation}
f_i = 1.029\,Y_i - 0.065\,X_i - 0.245\,Y_i^2 + 0.0018\,X_i^2 + 0.0215\,Y_i^3,\qquad 0\le f_i \le 1.
\end{equation}
% Εικόνα: τύποι X,Y και πολυώνυμο f από τις διαφάνειες/ΤΟΤΕΕ
Ο ετήσιος ηλιακός συντελεστής κάλυψης είναι $SF=\dfrac{\sum_i L_i f_i}{\sum_i L_i}$.

\paragraph{Συντελεστές διόρθωσης.}
Για Ζ.Ν.Χ. μόνο, $k_2 = \dfrac{11.6 + 1.18\,T_{hw} + 3.86\,T_{cw,i} - 2.32\,\bar{T}_{a,i}}{100-\bar{T}_{a,i}}$ (από οδηγό/ΤΟΤΕΕ). % Εικόνα: τύπος k2
Για επαρκή εναλλάκτη, $k_3=1$, ενώ $k_1$ βάσει κυκλοφορητή/στρωμάτωσης. % Εικόνα: υπόδειξη τιμών k1,k3

\section{Επίλυση ανά υποερώτημα}
\subsection{Υποερώτημα 1: Επιφάνεια συλλεκτών $A_c$ για $SF\geq 0.6$}
Με \emph{σάρωση} της $A_c$ και υπολογισμό $f_i$ ανά μήνα, αναζητείται το ελάχιστο $A_c$ ώστε $SF \ge 0.6$. % Εικόνα: ροή αλγορίθμου f-chart
\paragraph{Κώδικας (MATLAB) που χρησιμοποιήθηκε.}
\begin{lstlisting}[language=Matlab,caption={Υποερώτημα 1: Αναζήτηση $A_c$ για $SF\ge 0.6$}]
for Ac = 0:Ac_max
   
     X = (Ac./L).*FR_mult_Ul.*FRdot_div_FR.*(Tanaf - Ta).*dt.*k1.*k2;

     Y = (Ac./L).*FR_mult_tan.*FRdot_div_FR.*ta_div_tan.*Hb.*k3;

     f = 1.029*Y - 0.065*X - 0.245.*(Y.^2) + 0.0018.*(X.^2) + 0.0215.*(Y.^3);
     f_sum = sum(f) ;
     
     % Ασφάλεια: αν f_sum == 0, προχώρησε στο επόμενο Ac (αποφυγή διαίρεσης/NaN)
    if f_sum == 0
        continue
    end

     Li_mult_fi = L.*f ;
     SF =  sum(Li_mult_fi)/sum(L);
     
     if SF >= 0.6
        Ac_found = Ac;
        break
    end
end

% Εμφάνισε αποτέλεσμα
if ~isnan(Ac_found)
    fprintf('Βρέθηκε Ac = %d με SF = %.4f\n', Ac_found, SF);
else
    fprintf('Δεν βρέθηκε Ac <= %d που να δίνει SF >= 0.6. Τελευταίο SF = %.4f\n', Ac_max, SF);
end

%--------------------------------------------------------------------------------------------
\end{lstlisting}

\subsection{Υποερώτημα 2: Όγκος δεξαμενής αποθήκευσης}
Σύμφωνα με την εκφώνηση, λαμβάνεται $V_{\text{tank}} = 75\,A_c$ [\si{\liter}] ως αρχική υπόθεση, και ελέγχεται επάρκεια έναντι μηνιαίου φορτίου αιχμής. % Εικόνα: κανόνας διαστασιολόγησης δεξαμενής

\begin{lstlisting}[language=Matlab,caption={Υποερώτημα 2: Υπολογισμός δεξαμενής και φορτίου ΖΝΧ}]

\subsection{Υποερώτημα 3: Συμβατική πηγή και εκπομπές}
Υπολογίζεται η απαιτούμενη ενέργεια συμβατικής πηγής για την κάλυψη του υπολοίπου φορτίου και οι αντίστοιχες εκπομπές CO\textsubscript{2} με και χωρίς ηλιακό σύστημα (συντελεστές εκπομπών από οδηγό). % Εικόνα: συντελεστές εκπομπών / παραδοχές
\paragraph{Κώδικας (MATLAB) που χρησιμοποιήθηκε.}
\begin{lstlisting}[language=Matlab,caption={Υποερώτημα 3: Συμβατική ενέργεια και εκπομπές}]
h_boiler = 0.8 ; % "σελίδα 34 οδηγός εργασίας"

 E_fuel = Qdem_HW*365/h_boiler ;
 mCo2 = EF_CO2*E_fuel ;
 

 h_pump = 0.4 ; % η αντλία θερμότητας καλύπτει το 40 % φορτίου

 E_el = QHW*365*h_pump/COP ;

 Dm_Co2 = (mCo2 - mCo2_new)

\end{lstlisting}

\subsection{Υποερώτημα 4: Εποχιακή αποθήκευση}

\section{Συμπεράσματα}
Παρουσιάστηκε η μεθοδολογία f-Chart για τη διαστασιολόγηση ηλιοθερμικού συστήματος Ζ.Ν.Χ. σε ξενοδοχειακή μονάδα \num{300} κλινών στην κλιματική ζώνη \textDelta. Η διαδικασία είναι αναπαραγώγιμη και στηρίζεται σε δεδομένα/συντελεστές των ΤΟΤΕΕ 20701-1/2017 και 20701-3/2010. % Εικόνα: σύνοψη/διάγραμμα ροής
